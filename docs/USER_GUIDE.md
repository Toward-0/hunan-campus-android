# 使用指南

适用版本：**0.2.21-compat-s1 / versionCode 33**。

## 下载与安装

从[版本发布页](https://github.com/Toward-0/hunan-campus-android/releases/tag/v0.2.21-compat-s1)下载 `ESurfingHunan-0.2.21-compat-s1-candidate-phone.apk`。普通手机无需下载源码压缩包，也不要安装名称含 `isolation` 的开发测试包。

应用设计支持 Android 8.0 / API 26 起，安装包包含 `arm64-v8a` 和 `armeabi-v7a`。已验证环境和未验证范围见[仓库首页](../README.md)。使用其他型号时，应先完成一次短时连接确认，再判断是否适合日常使用。

打开下载好的 APK，根据系统提示允许本次安装。已有同签名版本时，优先覆盖安装以保留数据；如果提示签名冲突、版本不兼容或安装失败，请停止安装并反馈，不要直接卸载或清除原应用数据。更新可能结束旧进程，完成后需自行打开并手动连接。

当前 APK 使用测试签名。未来正式签名版本可能需要单独的安装和数据迁移步骤。

如需在 Windows 核对下载文件，可在 PowerShell 执行：

```powershell
Get-FileHash -LiteralPath '.\ESurfingHunan-0.2.21-compat-s1-candidate-phone.apk' -Algorithm SHA256
```

应得到：

```text
7D73C1C63A746E5747E1A41D4100ED83F9036C0C4C0BC6A721E4513E6320AE2D
```

## 第一次连接

1. 先在系统 Wi-Fi 设置中直接连接校园 Wi-Fi。
2. 打开应用，在账号页输入校园网账号和密码。
3. 首次使用保持门户、IP、网关、MAC、mscgip、主机名等高级项为空，由应用自动发现；不要复制另一部手机的网络身份参数。
4. 点击一次“保存并连接”，等待结果。首次确认最多观察 5 分钟，期间不要连续点击连接、注销或修复。
5. 查看连接状态与外网检测结果。认证或心跳成功不代表每一时刻的外网都已验证；外网检测也可能受校园网络和目标站点状态影响。

失败或超时后点击“停止连接”，记录页面提示再反馈。无需把账号密码发给项目维护者。

## 日常使用与后台运行

应用会维护已认证会话的心跳并进行有限的外网检测。系统权限、Doze 和厂商省电设置可能影响后台执行；根据手机实际设置按需调整，并观察连接结果。当前尚未完成各权限组合和 8 小时自然锁屏验证，短时连接成功不代表长期锁屏稳定性已经通过。

网络丢失、网络身份变化或应用进程终止后，应用不会自动重放账号登录。强制停止、设备重启后也需要重新打开并手动连接。

## 停止、注销与换机

| 操作 | 作用 |
|---|---|
| 停止连接 | 停止本机连接工作，不请求服务器注销 |
| 注销并停止 | 请求结束当前服务器会话；以应用提示的注销结果为准 |
| 断开 Wi-Fi、关闭应用 | 不能据此判断服务器会话已经注销 |

准备换手机登录时，在旧手机仍连着校园 Wi-Fi、仍保有当前会话时，先点击“注销并停止”，确认成功后再断开 Wi-Fi，随后在新手机输入账号密码并手动连接。

如果旧手机已停止或进程已经消失，不保证仍有可用于注销的本机会话。不要为了尝试注销反复登录；可先核实账号当前状态或使用校园网提供的账号管理渠道。

## 修复网络

打开“更多 → 修复网络”。入口始终可见，应用会检查当前是否具备修复条件；条件不满足时会说明原因。

修复用于已有认证会话受到持续门户拦截的情况。满足条件并由你确认后，应用先注销当前会话；只有注销获得认可的成功响应，才按客户端策略等待 100 秒，然后至多重新登录一次。100 秒是应用采用的等待策略，不是已确认的服务器要求。

修复等待可以取消。停止连接、网络变化或服务结束会取消尚未执行的修复。没有本机已认证会话时，修复入口不能用于强制登录或结束另一台设备的会话。

## 反馈问题

提交[问题反馈](https://github.com/Toward-0/hunan-campus-android/issues)时，建议包含：

- 手机型号、Android 版本、应用版本。
- 是否直接连接校园 Wi-Fi。
- 简短的操作顺序、最终页面提示及发生时间。
- 是否只在锁屏、大字体、键盘弹出或特定导航模式下出现。

不要上传账号、密码、票据、密钥、完整抓包或未经检查的完整日志。截图前先检查是否露出账号及其他个人信息。维护者需要更多证据时，会提供限定字段的收集方法。
