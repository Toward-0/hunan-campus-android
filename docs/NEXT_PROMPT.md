2. 离线集成/压力/故障注入只使用隔离包、设备内部127.0.0.1、合成模块与虚构凭据。不得回退生产或外网；若用主机回环要明确adb reverse。测试入口和故障注入不能进入主APK。
3. 已授权你在实际连接的手机上进行必要安装、隔离测试、系统/权限检查及白名单采集；每次明确设备序列号、包名、APK，核对ABI与退出码，有超时和清理恢复。不默认root，不清空或卸载主应用，不因上一台曾连接就默认当前仍是它。真实账号登录、注销、确认修复仍由我手动操作；不要请求账号密码给你。
4. 实网方案先列登录/注销上限、探测频率、最长时间、停止条件和失败处理。保持正常心跳与预算探测，不制造高频认证/注销。只采集白名单字段，不导出账号、密码、票据、密钥、凭据文件或完整抓包，不先全量采集再脱敏。
