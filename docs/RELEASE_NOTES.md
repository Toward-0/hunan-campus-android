# 湖南校园网 Android 0.2.21

面向使用者提供的试用交付版，版本为 **0.2.21-compat-s1 / versionCode 33**。本次将现有成果整理为可下载的 GitHub 发布，沿用原 APK，不包含新的应用代码改动或重新构建。

## 下载后可以做什么

- 直接连接校园 Wi-Fi，输入账号和密码，通过自动门户发现完成连接。
- 查看连接状态，维护已认证会话心跳并检查外网可用性。
- 在“更多 → 修复网络”查看条件，并在需要时主动确认修复。
- 使用同一个手机 APK 安装到支持 ARM64 或 ARM32 的安卓手机。

请下载 `ESurfingHunan-0.2.21-compat-s1-candidate-phone.apk`，安装和使用步骤见[使用指南](https://github.com/Toward-0/hunan-campus-android/blob/main/docs/USER_GUIDE.md)。更换手机前，请在原手机仍联网时先“注销并停止”，确认成功后再切换。

## 兼容性与当前不足

设计支持 Android 8.0 / API 26 起，targetSdk 35；手机 ABI 为 `arm64-v8a` + `armeabi-v7a`。

| 已验证设备 / 环境 | 系统与页大小 | 验证范围 |
|---|---|---|
| realme RMX3820 | Android 14 / API 34 / 4KB | 主包安装与实网成功；同版本隔离包 ARM64、ARM32 JNI 通过 |
| iQOO 12（V2307A） | Android 15 / API 35 / 4KB | 主包安装、仅账号密码实网连接成功；同版本隔离包 ARM64 JNI 通过 |
| API 35 模拟器 | x86_64 / 4KB | 隔离专项测试，仅代表该模拟器环境 |

仍需完善：ARM64 / 16KB 页大小运行验证、当前版本旧 Android 系统完整回归、其他厂商实机验证、API 35 大字体状态栏裁切及全部 UI 组合。诊断导出的完整性仍待完善；Doze 组合和 8 小时自然锁屏尚未验证，不能据短时联网宣称长期后台稳定。

当前保留测试签名；未来迁移正式签名时，不能保证直接覆盖安装。完整兼容性和后台稳定性验收尚未完成，本次发布不改变这些验证边界。

## 使用行为

网络丢失、身份变化、进程终止、强制停止或重启后等待手动连接，不自动开机登录。修复由用户确认，仅在自身注销成功后等待并至多重登一次；停止或网络变化会取消待执行修复。
