## 有代码或历史日志支持的项目

| 项目 | 基线依据 | 本轮处理 |
|---|---|---|
| 网络丢失后可自动重新提交账号 | SessionService.onLost 保持 running=true，onAvailable 会 activate/authenticate | 丢失选中网络后关闭代次、停止服务，等待手动连接 |
| IPv4/网关变化会自动认证 | onLinkPropertiesChanged→activate，新指纹导致新代次 | 当前身份变化即取消；修复等待同样终止 |
| 等待门户时重复点连接会重新开始 | start 特意排除 WAITING_WIFI 的去重 | 活动连接、发现和注销阶段 start 均幂等；修改设置需停止后重新连接 |
| 已取消的延迟任务仍可能留在队列 | Executors.newSingleThreadScheduledExecutor 默认不启用 removeOnCancelPolicy | 显式 ScheduledThreadPoolExecutor，取消即移除 |
| 调度注册与取消存在竞态 | tokens.put 与 WakeupDispatch.register/闹钟安装之间可发生 cancelAll；timer fallback 直接 deliver 未删除静态回调 | 注册/取消同步；所有交付路径移除回调；销毁清理主线程消息 |
| 旧响应可能修改新代次心跳间隔 | interval() 无代次限定地更新全局 SessionState | 加入代次条件，记录该代次 |
| 修复等待中服务结束后界面可能仍显示正在修复 | onDestroy 仅以 running 判断中断，但修复等待时 running=false | 销毁前合并 running/repairInProgress 判断，并报告 INTERRUPTED |
| HTTP 资源所有权不足 | 每次 Network.openConnection 隐式建立平台池，只有单请求 disconnect，无显式代次池销毁；历史 100 次测试出现增长 | 每个 HttpScope 拥有 OkHttp 池；网络 DNS/SocketFactory 绑定 Wi-Fi，结束取消调用并 evictAll；无跨代次 Network 缓存 |
| 默认探测作用域没有明确关闭 | InternetCheck/PortalDiscovery 默认参数直接构造 HttpScope | 自有作用域 use/finally 关闭，外部作用域由会话负责 |
| 缓存无法区分不同 Wi-Fi 网络实例 | IdentityCache 仅检查 IP、网关和 24 小时时间 | 增加开机编号及网络 handle，仍须重新验证外网；不更改设备 MAC/客户端标识 |
| 动态模块短解压数据会越界读取 | ios_zsm.c 在验证 dest_len 前读取 0xFF/0xFC/0xFA | 先检查精确解压长度及头长度，再读字段；拒绝非完整 TEA 块 |

正常注销的状态与提示更新在基线已经带 generation 检查，并非已证实的缺陷。早期审查将其列为疑点，逐行复核后撤回；本轮增加的是重复注销去重、销毁保护及迟到响应回归。NativeSession 构造期间算法标识获取失败时补 close 属防御性清理，目前没有真实句柄泄漏日志证明该路径发生过。

## 保持及明确的行为

- 认证接受与 HTTPS 出网分别判断。HTTP 返回门户而两个 HTTPS 都失败才记录 PORTAL_REQUIRED；单个 HTTPS 故障不触发注销修复。
- 发现门户有限复查时尚未提交账号；认证失败不自动循环提交。
- 修复由用户在确认对话框中启动，只有自己的注销收到已支持协议成功响应后，才允许等待后登录一次。
- 100 秒是客户端保守等待策略，没有服务端冷却要求的证据。停止、网络丢失、身份变化、服务结束后取消等待。
- 新传输不跟随重定向、不重试连接；POST body 标记 one-shot，连 HTTP 408/503 的内部 follow-up 也不能重放账号。
- 保留现有简约界面，仅修正修复确认文案与诊断标识；不扩展网络、架构、厂商或发布渠道。

## 传输边界

使用固定版本 OkHttp 4.12.0、Okio JVM 3.6.0；原始 Maven 地址、SHA-256、许可证在 `third-party/`。只用 HTTP/1.1，保留协议头、固定长度请求体、HTTP 状态和 Error-Code 处理；使用平台默认 TLS 验证，不加信任绕过。每个代次拥有池，Android 网络对象仅存活于该代次。共享的是依赖库的后台清理执行器，不能仅依据线程总数作泄漏判断；测试同时采样池、请求、队列、回调、句柄和 FD。

隔离服务器全部绑定 127.0.0.1，合成模块来自 `tests/make-synthetic-module.py`。模拟 HTTPS 证据由隔离子类重写为本地 HTTP 故障模型，只能证明状态决策，不能证明 TLS/Wi-Fi 出网；真实 Wi-Fi HTTPS 必须另测。

最终测试结果、设备身份、签名/覆盖安装及剩余限制见交付目录验证记录。没有达到验证条件的项目不得按通过交付。
