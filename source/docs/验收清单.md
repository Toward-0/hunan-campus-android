# 验收清单

## 支持目标

- iQOO 12，用户提供软件版本 PD2307C_A_15.1.17.4.W10.V000L1。
- Android API 版本以 adb 查询为准；不以软件版本号推断。
- 真实校园 Wi-Fi 与账号由用户现场提供。

## 必须记录

- 安装和首次启动是否成功、是否请求通知权限。
- 未认证 Wi-Fi 与移动数据同时开启时，认证是否确实走 Wi-Fi。
- 门户身份参数来源；只保存脱敏说明，不保存密码/票据/完整重定向。
- 认证各端点 HTTP/协议码；外网实际访问结果。
- 100 次启停、请求中停止、Wi-Fi 断开/重连各 10 次。
- 锁屏 8 小时，心跳次数、最长延迟、断线原因、恢复次数、耗电对照。
- 错误密码只测试受控次数，不无限试错。
- 注销与停止行为分开；测试注销可能中断当前网络。
- 同账号 PC/手机并机行为；升级安装的凭据保留。

## 当前边界

无校园网实测之前，不能标记“可用产品”。本机 JNI 检查也不能证明 ARM64 JNI、HTTP 报文和服务端兼容性已通过。
