# 安装与测试说明 — 0.2.2

2026-10-31。当前手机已安装本版；APK 为 arm64 测试签名包，可覆盖同包名旧验证版，已验证升级保留本机账号配置。源码和 APK 均不包含个人凭据或签名私钥。

## 使用

1. 先在官方客户端注销并退出。官方客户端的 VPN 会影响测试版直接绑定 Wi-Fi 的请求。
2. 连接 ChinaNet-Young。首次验收关闭移动数据，避免把其他网络的上网能力误当作校园 Wi-Fi 成功。
3. 首页输入账号密码；已有配置可直接使用，密码留空保留已保存值。
4. 设置默认选择“iOS 兼容通道”。这是当前 Android 应用采用的服务器协议选项，已在本机完成独立上网验证；官方原生 Android 通道尚未实现。
5. 门户、IPv4、网关、MAC、mscgip 默认留空。已有手填值优先；设置页可查看实际值及来源。不要把 DNS 当作网关或 mscgip。
6. 点“保存并登录”，等待“已认证 · Wi-Fi 外网检测通过”，再用浏览器确认网页能打开。

## 操作与诊断

- “停止客户端 · 不注销”：结束本地工作；不向服务器注销。网络变化、重新打开页面不会自行重登。
- “注销并停止”：请求服务端注销，当前实测返回 HTTP200、协议码0、空响应体，界面可确认注销。可再次点登录。
- “仅检测 Wi-Fi”：不读取或提交账号，探测当前 Wi-Fi 门户及外网。
- “日志 → 复制脱敏诊断”：保留最近1024条内存日志、每条最多1000字符，复制最多128000字符。进程结束后内存日志丢失。内容不包含密码、票据、MAC和完整会话地址；设置页的运行身份不要直接当作脱敏诊断分享。

门户已经不再返回身份参数时，客户端会在重新验证外网可用后使用同IPv4/网关、24小时内的历史身份缓存。随机MAC变更后应清除缓存或填写当前值；缓存不保存账号密码或会话票据。

- realme RMX3820、Android14（用户提供系统为realme UI5.0）、ChinaNet-Young。
- 四页原生界面，独立登录及HTTPS外网，服务端确认注销、再次登录。

- 动态C上下文：100次创建/释放、UTF-8与块边界、失效句柄、容量回收、4000次并发往返、并发释放后重启。
- Gradle构建、Lint和v2/v3签名检查通过。Lint为0错误、10警告。
- 正在等待网络响应时停止及迟到结果：本地端点确认请求到达后延迟8秒，客户端停止后状态保持，迟到响应未覆盖；通过。

## 限制与下一阶段

这是可上网的验证版，不是后台稳定性或商店发布验收完成版。八小时正常锁屏、耗电对照、进程回收后的恢复、密钥失效迁移、错误密码分类与其他机型尚未完整验收。只测试了覆盖升级，未清空当前手机数据做新版全新安装测试。

当前保活按服务端interval设定，并设置范围和异常回退；实际调度使用提前量。该调度策略仍需长期锁屏观察，不能据本次interval=300推导所有服务端规则。

连续心跳失败会停止，要求手动检查；没有无限账号重试。对“心跳仍返回成功但外网被静默踢线”的持续检测与自动恢复仍需完善，不承诺多设备同账号永不互踢。首页外网结果反映最近一次检测。

协议使用HTTP和应用层加密，没有TLS保护。APK使用既有测试签名；正式签名、密钥备份与发布尚未完成。
